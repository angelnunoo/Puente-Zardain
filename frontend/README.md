# Frontend - Puente de Zardain

Aplicación Next.js para clientes y panel admin.

## Páginas

- `/`: Home
- `/login`: Iniciar sesión
- `/register`: Registrarse
- `/menu`: Carta digital
- `/cart`: Carrito
- `/admin`: Panel administrativo

## Características

- Responsive design (PC + móvil + tablet)
- Autenticación con JWT
- Comunicación en tiempo real con Socket.IO
- Tailwind CSS para estilos

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Producción

```bash
npm run build
npm run start
```
